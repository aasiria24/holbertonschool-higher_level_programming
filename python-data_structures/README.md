# Python - Data Structures: Lists, Tuples

This directory contains solutions for the Holberton School project **Python - Data Structures**.
The project focuses on understanding and practicing **lists**, **tuples**, basic sequence operations, and common list patterns.

## Requirements
- Python 3.8.5 (Ubuntu 20.04 LTS)
- First line of every script: `#!/usr/bin/python3`
- Code style: `pycodestyle` (version 2.7.*)
- All files must be executable and end with a new line

## Files

### Mandatory Tasks
- **0-print_list_integer.py**
  - Prints all integers of a list (one per line) using `str.format()`.

- **1-element_at.py**
  - Retrieves an element from a list safely (returns `None` if index is invalid).

- **2-replace_in_list.py**
  - Replaces an element at a specific position in a list (modifies the original list only if index is valid).

- **3-print_reversed_list_integer.py**
  - Prints all integers of a list in reverse order (one per line).

- **4-new_in_list.py**
  - Replaces an element in a **new copy** of a list (original list is not modified).

- **5-no_c.py**
  - Removes all characters `c` and `C` from a string (without using `str.replace()`).

- **6-print_matrix_integer.py**
  - Prints a matrix of integers with the required formatting.

- **7-add_tuple.py**
  - Adds two tuples (uses 0 for missing values and ignores extras beyond the first two elements).

- **8-multiple_returns.py**
  - Returns a tuple containing the length of a string and its first character (`None` if empty).

- **9-max_integer.py**
  - Finds and returns the biggest integer in a list (returns `None` if the list is empty).

- **10-divisible_by_2.py**
  - Returns a list of booleans indicating whether each element is divisible by 2.

- **11-delete_at.py**
  - Deletes an item at a specific position in a list (without using `pop()`).

- **12-switch.py**
  - Switches the values of two variables in exactly 5 lines.
