# Python - Hello, World

This project is part of the Holberton School curriculum and focuses on learning the basics of Python programming.

## Project Description

The goal of this project is to get familiar with:
- Using the Python interpreter
- Printing text and variables
- Working with strings
- Indexing and slicing
- Following Python coding style (PEP 8)
- Validating code using `pycodestyle`

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- All scripts are interpreted on Ubuntu 20.04 LTS using `python3` (version 3.8.*)
- The first line of each file must be exactly:
#!/usr/bin/python3
- All files must be executable
- Code must follow `pycodestyle` (version 2.7.*)
- All files must end with a new line

## How to Run

chmod +x filename.py
