# Python - Server-Side Rendering

A Flask web application that demonstrates server-side rendering using the Jinja2 templating engine. The project covers dynamic content generation, multiple data sources, and reusable templates.

## Learning Objectives

- Understand the difference between server-side and client-side rendering
- Set up and use Flask with Jinja2 templates
- Read and display data from JSON, CSV, and SQLite sources
- Handle dynamic content, query parameters, and edge cases

## Requirements

- Python 3.x
- Flask (`pip install Flask`)
- SQLite (built into Python)

## Files

| File | Description |
|------|-------------|
| `task_00_intro.py` | Generates personalized invitation files from a template and a list of attendees using string templating |
| `task_01_jinja.py` | Basic Flask app with reusable header/footer templates across Home, About, and Contact pages |
| `task_02_logic.py` | Flask app with a dynamic `/items` route that reads from `items.json` and uses Jinja loops and conditionals |
| `task_03_files.py` | Flask app with a `/products` route that reads from JSON or CSV based on the `source` query parameter |
| `task_04_db.py` | Extends Task 3 to also support SQLite as a data source via `source=sql` |
| `create_db.py` | Script to initialize and populate the `products.db` SQLite database |

## Data Files

| File | Description |
|------|-------------|
| `items.json` | List of items used by Task 2 |
| `products.json` | Product data in JSON format used by Tasks 3 and 4 |
| `products.csv` | Product data in CSV format used by Tasks 3 and 4 |
| `products.db` | SQLite database generated by `create_db.py`, used by Task 4 |

## Templates

All HTML templates are located in the `templates/` folder:

| Template | Description |
|----------|-------------|
| `header.html` | Reusable header with navigation links |
| `footer.html` | Reusable footer |
| `index.html` | Home page |
| `about.html` | About page |
| `contact.html` | Contact page |
| `items.html` | Displays a list of items with empty state handling |
| `product_display.html` | Displays product data in a table with error message support |

## Usage

### Task 1 — Basic Flask App
```bash
python3 task_01_jinja.py
```

### Task 2 — Dynamic Items Page
```bash
python3 task_02_logic.py
# Visit: http://localhost:5000/items
```

### Task 3 — JSON and CSV Data Sources
```bash
python3 task_03_files.py
# Visit: http://localhost:5000/products?source=json
# Visit: http://localhost:5000/products?source=csv
# Visit: http://localhost:5000/products?source=json&id=1
```

### Task 4 — SQLite Data Source
```bash
python3 create_db.py   # Run once to create the database
python3 task_04_db.py
# Visit: http://localhost:5000/products?source=sql
# Visit: http://localhost:5000/products?source=json
# Visit: http://localhost:5000/products?source=csv
```

## Query Parameters — `/products` Route

| Parameter | Values | Description |
|-----------|--------|-------------|
| `source` | `json`, `csv`, `sql` | Selects the data source |
| `id` | Any integer | Filters results by product ID (optional) |

### Error Handling

| Scenario | Response |
|----------|----------|
| Invalid `source` | "Wrong source" |
| `id` not found | "Product not found" |
| Database error | "Database error: ..." |
